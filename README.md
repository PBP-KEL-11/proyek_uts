# 🌱 Tanamin

Website pengingat perawatan tanaman yang membantu pemula dan pecinta tanaman merawat tanamannya secara konsisten melalui jadwal otomatis dan skor **Jejak Hijau**.

## 📖 Deskripsi

Tanamin adalah website pengingat perawatan tanaman yang membantu pemula urban farming dan pecinta tanaman hias agar tidak lagi kehilangan tanaman karena lupa jadwal siram atau pupuk. Banyak orang mulai tertarik berkebun di rumah, tapi berhenti di tengah jalan karena tanamannya mati akibat kelalaian jadwal perawatan — bukan karena kurang niat, tapi karena tidak ada sistem pengingat yang disesuaikan dengan kebutuhan tiap jenis tanaman.

Tanamin menjawab masalah ini dengan jadwal perawatan otomatis berbasis data kebutuhan tiap jenis tanaman, dilengkapi skor **"Jejak Hijau"** yang memotivasi pengguna untuk konsisten merawat tanamannya. Website ini mendukung gaya hidup *Sustainable Living* lewat sub-tema **Urban Farming & Biodiversity**.

## 🧩 Daftar Modul

| No. | Modul | Deskripsi |
|---|---|---|
| 1 | Autentikasi & Profil Pengguna | Register, login, edit profil |
| 2 | Catatan & Jurnal Pribadi (Plant Notes) | Pencatatan teks simpel untuk mencatat progres atau kejadian penting pada tanaman tertentu |
| 3 | Jadwal & Pengingat Perawatan | Set interval siram/pupuk per tanaman, dashboard "tugas hari ini", log riwayat perawatan |
| 4 | Integrasi Public API Data Tanaman | Cari jenis tanaman + info kebutuhan perawatan dari API, isi otomatis rekomendasi jadwal, CRUD model tanaman |
| 5 | Skor Jejak Hijau, Statistik & Admin | Gamifikasi ringan (skor/badge keberhasilan rawat tanaman), dashboard statistik keseluruhan, moderasi data |

## 🔌 Public API / Mock API

- **Utama:** [Perenual Plant API](https://perenual.com/docs/api) — data jenis tanaman, kebutuhan cahaya, air, dan panduan perawatan.
- **Cadangan:** Trefle API, atau mock API sendiri jika limit Perenual tidak mencukupi kebutuhan seeding 50+ data.

## 👤 Peran Pengguna

- **Pengguna (Member):** mendaftar, menambahkan tanaman pribadi, melihat jadwal perawatan, membuat catatan untuk tanaman, melihat skor Jejak Hijau.
- **Admin:** memoderasi data, memantau statistik pengguna secara keseluruhan.
